# PostureSense 기반 자세 인식 기능 개발 기록

**작업일:** 2026.10.21  
**작업 목적:** 온디바이스 대화형 자세 교정 시스템의 자세 인식 기능 구현 및 검증

## 1. 개발 개요

기존 오픈소스 PostureSense의 자세 분류 기능을 활용하여 사용자의 초기 자세를 등록하고, 등록된 자세를 기준으로 실시간 머리 위치 변화를 감지하는 기능을 추가하였다.

기존 Good / Fair / Poor 자세 분류 기능은 유지하면서 초기 자세 등록 및 머리 위치 비교 기능을 별도로 구현하였다.

## 2. 구현 내용

### 2.1 실시간 자세 인식 및 분류

- MediaPipe Pose Landmarker를 활용한 관절 좌표 추출
- PostureSense의 Random Forest 기반 Good / Fair / Poor 자세 분류 기능 활용
- 귀·어깨 좌표, 목 기울기(`neck_inclination`), 머리 위치 오프셋(`head_forward_offset`) 출력
- 기존 8프레임 다수결 방식의 자세 분류 결과 안정화 기능 활용

### 2.2 초기 자세 등록(캘리브레이션)

- Good 자세가 연속으로 5초 이상 유지되면 초기 기준 자세 등록
- Fair 또는 Poor 판정 시 등록 진행 상태 초기화
- Good 상태에서 수집한 머리 위치 오프셋의 평균값을 기준값으로 저장
- 수집된 값의 변동이 크거나 샘플 수가 부족하면 등록 재시도

현재는 프로그램 실행 후 Good 자세가 감지되면 자동으로 초기 자세 등록이 시작된다.

### 2.3 실시간 머리 위치 변화 감지

- 초기 등록된 기준값과 현재 머리 위치 오프셋 비교
- 최근 10프레임 평균값을 활용하여 측정값 평활화
- 기준값과 현재값의 차이가 임시 임계값 `0.10`을 초과하면 `head_changed=True` 반환
- 현재는 머리의 전방 및 후방 이동을 구분하지 않고 위치 변화 여부를 감지

## 3. 수정 및 추가 파일

| 파일 | 변경 사항 |
|---|---|
| `ai/head_posture_detector.py` | 초기 자세 등록 및 실시간 머리 위치 비교 기능 구현 |
| `posture_monitor.py` | 자세 분류 결과와 신규 기능 연결 및 디버그 출력 추가 |

기존 PostureSense의 주요 분류 기능은 유지하였다.

## 4. 실행 방법

### 4.1 실행 환경

- Python 실행 환경
- 웹캠 또는 노트북 내장 카메라
- MediaPipe, OpenCV 등 프로젝트에서 사용하는 Python 라이브러리
- PostureSense 실행에 필요한 모델 및 설정 파일

프로젝트에 포함된 의존성 목록과 기존 `README.md`를 참고하여 실행 환경을 구성한다.

### 4.2 프로젝트 실행

VS Code에서 `PostureSense-main` 폴더를 연다.

터미널을 실행한 뒤 현재 위치가 프로젝트 최상위 폴더인지 확인한다.

```powershell
cd PostureSense-main
```

이미 해당 폴더에서 터미널을 실행했다면 위 명령어는 생략한다.

이후 다음 명령어를 입력한다.

```powershell
python start_posture_monitor.py
```

정상적으로 실행되면 카메라 화면이 표시되고 자세 인식이 시작된다.

카메라가 실행되지 않는 경우 `config.py`의 `CAMERA_INDEX` 설정과 카메라 연결 상태를 확인한다.

### 4.3 초기 자세 등록 방법

1. 프로그램을 실행하고 카메라에 상반신이 보이도록 위치를 조정한다.
2. 바른 자세를 취한다.
3. PostureSense에서 Good 자세가 감지되면 자동으로 5초 카운트가 시작된다.
4. Good 상태를 연속으로 5초 이상 유지하면 초기 기준값이 저장된다.
5. 등록이 완료되면 실시간 머리 위치 비교 기능이 실행된다.

현재 초기 자세 등록 기능은 자동 실행 방식이며, 향후 앱의 자세 측정 시작 버튼과 연동하여 사용자가 직접 등록을 시작하도록 개선할 예정이다.

### 4.4 실행 결과 확인

초기 자세 등록 중에는 다음과 같은 메시지가 출력된다.

```text
[Head] {'status': 'calibrating', 'progress': 0.403}
```

- `calibrating`: 초기 자세 등록 진행 중
- `progress`: 5초 기준 등록 진행률(0.0~1.0)

등록이 완료되면 다음과 같은 메시지가 출력된다.

```text
[Head] {'status': 'calibrated', 'baseline': -0.0784}
```

- `calibrated`: 초기 자세 등록 완료
- `baseline`: 등록된 머리 위치 기준값

등록 이후에는 다음과 같은 메시지가 출력된다.

```text
[Head] {
    'status': 'monitoring',
    'baseline': -0.0784,
    'current': -0.1412,
    'deviation': 0.0628,
    'head_changed': False
}
```

| 항목 | 설명 |
|---|---|
| `baseline` | 초기 등록된 머리 위치 기준값 |
| `current` | 현재 머리 위치 오프셋의 최근 10프레임 평균 |
| `deviation` | 초기 기준값과 현재값의 절댓값 차이 |
| `head_changed` | 임시 임계값 0.10 초과 여부 |

`head_changed=True`는 초기 자세에서 머리 위치 변화가 일정 기준 이상 발생했음을 의미한다.

단, 현재는 거북목 여부를 직접 진단하는 값이 아니다.

### 4.5 테스트 방법

다음과 같은 자세를 각각 취하면서 출력값 변화를 확인한다.

1. 바른 자세 유지
   - 초기 기준값 등록 여부 확인
   - 머리 위치 변화량이 안정적으로 유지되는지 확인

2. 머리만 앞으로 내밀기
   - `head_forward_offset` 변화 확인
   - 기준 자세와의 변화량 확인

3. 상체 앞으로 기울이기
   - Good / Fair / Poor 분류 결과 확인
   - 머리 위치 변화량에 미치는 영향 확인

4. 원래 자세로 복귀
   - 변화량이 감소하는지 확인
   - `head_changed` 상태 변화 확인

가능하면 카메라를 오른쪽 측면에 고정하고 동일한 거리와 각도에서 테스트하는 것을 권장한다.

### 4.6 프로그램 종료

실행 중인 카메라 창에서 `Q` 키를 눌러 프로그램을 종료한다.

종료 시 세션 요약이 출력되며, 세션 기록 기능이 활성화되어 있다면 `data/sessions/`에 기록이 저장될 수 있다.

## 5. 테스트 결과

2026년 10월 21일 노트북 내장 카메라를 이용하여 기능 동작 테스트를 진행하였다.

- Good 자세 5초 유지 후 기준값 저장 확인
- 자세 변화에 따른 Good / Fair 분류 결과 변경 확인
- 초기 기준값과 현재 머리 위치 차이 계산 확인
- 실시간 모니터링 상태 반환 확인
- 테스트 중 프로그램 실행 오류 없이 정상 종료

두 번째 테스트에서는 초기 기준값 `-0.0784`가 저장되었으며, 출력된 머리 위치 변화량의 최댓값은 약 `0.063`이었다.

현재 임계값 `0.10`을 초과하지 않아 `head_changed=False`가 유지되었다.

## 6. 한계 및 향후 개선 사항

- 노트북 내장 카메라 사용으로 고정된 측면 촬영 환경 확보에 어려움이 있었음
- PostureSense의 합성 데이터 기반 자세 분류 모델에 대한 실제 환경 정확도 검증 필요
- 초기 자세 등록 시 카메라 방향 및 사용자의 움직임에 따른 오차 가능성 존재
- 머리 위치 변화 감지 임계값 `0.10`은 임시 설정값으로 추가 검증 필요
- 사용자 요청에 따른 캘리브레이션 시작 기능 구현 예정
- 머리 전방 이동 방향 구분 및 지속시간 기반 판정 기능 보완 예정
- 실제 측면 웹캠 환경에서 추가 테스트 예정
- LLM의 전체 자세 확인(`type="0"`) 및 머리 위치 확인(`type="1"`) 명령과 연동 예정

## 7. 참고 사항

현재 구현된 머리 위치 감지 기능은 초기 등록 자세와 현재 자세의 상대적 차이를 계산하는 방식이다.

따라서 의학적으로 거북목을 진단하는 기능이 아니며, 실제 환경에서의 정확도 검증 및 임계값 조정이 필요하다.

원본 PostureSense의 기능 설명과 설치 관련 세부 사항은 기존 `README.md`를 참고한다.
